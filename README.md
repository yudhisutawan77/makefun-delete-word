## Entry

**queue**

Five letters, four of them silent: the letter Q with four letters queuing
behind it. Delete it and the word itself is a queue of letters — and the
language loses its word for standing in line. The humour comes from the
word's own spelling, not from shock, and it is a fresher pick than the
field's first thoughts, while still instantly understood by any reader.

## How it works

`main.py` writes exactly one word — `queue` — to `/output/entry.txt`
(no trailing newline, 5 bytes, 1 word), inside the gate of 1–77
characters of UTF-8 text.

## Run

```sh
python3 main.py
```
